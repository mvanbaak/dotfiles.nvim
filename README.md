# NeoVim configuration that works for me

## Overview

This repository holds my neovim configuration.
It might work for you, it might not.

After watching too many videos and reading a lot
of blogs etc, I decided to take what I liked from each
of them, and together with my old vim config started
building my own config. This is the result.

I try to keep it up-to-date, documented and structured.

## Requirements

The following list of 'requirements' is versions of software
this repository is tested with. It might work with other versions,
if needed test it.

* neovim 0.11.5 (0.11.3+ is needed because of some plugin APIs used)
* git 2.50.1
* a [Nerd Font](https://www.nerdfonts.com/)

Furthermore, plugins in use might have additional requirements.
Check the headers of the plugins files to find the URLs
to the seperate plugin repositories. (hopefully there's a
README with requirements there)

## Forking/Template/Contributing

Feel free to use this config as a template. Contributions are more then welcome.
Wether or not pull-requests will be merged depends on wether
I will use the functionality myself.
